ℹ️ ስለ Digital Attendance + Payroll

ይህ መተግበሪያ የሠራተኞችን መገኘት፣ የመግቢያና መውጫ ሰዓት፣ GPS መረጃ፣ የፈቃድ መዝገብ እና የደመወዝ ስሌት በዲጂታል መንገድ ለማስተዳደር የተዘጋጀ ነው።

መሪ መልዕክት: ችግርን በቴክኖሎጂ ወደ መፍትሔ መቀየር።

🎯 ለምን ተሠራ?

  • የሠራተኞች መገኘትን በግልጽና በተደራጀ መንገድ ለመመዝገብ።
  • የመግቢያና መውጫ መረጃን በቀላሉ ለመከታተል።
  • የፈቃድና የደመወዝ መረጃን በአንድ የአስተዳደር ገጽ ላይ ለማየት።
  • የወረቀት ሥራንና የስህተት እድልን ለመቀነስ።

🔭 የወደፊት ራዕይ

መተግበሪያውን በተቋማዊ ደረጃ በደህንነት ማስፋፋት፣ የሠራተኞችን መረጃ በአንድ የAdmin Dashboard ላይ በቀጥታ ማሳየት፣ የደመወዝ ስሌትን ማሻሻል እና ወደፊት ከሌሎች የተቋም ዲጂታል ሥርዓቶች ጋር ማገናኘት ነው።

ይህ የወደፊት ዕቅድ ነው፤ ከመደበኛ አጠቃቀም በፊት የደህንነት፣ የመረጃ ጥበቃና የPayroll ሙከራዎች መጠናቀቅ አለባቸው።

📘 የአጠቃቀም መመሪያ

  1. ከMenu የሚፈልጉትን የሥራ ክፍል ይምረጡ።
  2. Attendance ላይ Employee ID ይምረጡ፤ Check In/Check Out ይጠቀሙ።
  3. GPS ለመጠቀም የስልኩን Location ፈቃድ ይፍቀዱ።
  4. የፈቃድ መረጃን Leave ላይ ያስገቡ።
  5. Payroll ላይ መረጃ አስገብተው ስሌቱን ያስኬዱ።
  6. የተመዘገቡ መረጃዎችን በAdmin Dashboard ለማየት የAdmin ይለፍ ቃል ያስገቡ።
